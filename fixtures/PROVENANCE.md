# Fixture provenance

All fixtures are redistributable. `manifest.json` is the machine-readable
version of this table (used by the tests); `golden/*.obv.json` holds the output
of the reference parsers (OpenBoardView `cc76e69` + eagleview TVW reader from
OBV PR #366) for each fixture, produced by `npm run goldens`.

## Real files

| File | Format | Origin | Licence |
|---|---|---|---|
| `real/glasgow/glasgow-kicad-boardview.brd` | BRD2 / BRDOUT | Shipped in [whitequark/kicad-boardview](https://github.com/whitequark/kicad-boardview) (commit `da24793`) `example/example.brd`, produced by its pcbnew exporter from the Glasgow board | 0BSD |
| `real/glasgow/glasgow-kicad-boardview.bvr` | BVRAW_FORMAT_3 | Same repository, `example/example.bvr` | 0BSD |
| `real/glasgow/glasgow.kicad_pcb` | KiCad PCB (source) | Same repository, `example/example.kicad_pcb` (Glasgow revC3) | 0BSD |
| `real/glasgow/glasgow-kicad10.cad` | GenCAD 1.4 | `kicad-cli pcb export gencad` (KiCad 10.0.1) from `glasgow.kicad_pcb` | 0BSD (derived data) |
| `real/glasgow/glasgow-kicad10-flipped.cad` | GenCAD 1.4 | Same, with `--flip-bottom-pads --unique-pins` | 0BSD |
| `real/glasgow/glasgow-kicad10.d356` | IPC-D-356 | `kicad-cli pcb export ipcd356` (kept for future IPC-D-356 support; not parsed yet) | 0BSD |

## Synthetic files (`synthetic/`)

Generated by `npm run fixtures` (`tools/gen-fixtures.ts`). The board content is the
real Glasgow board (parts, pins, nets, pad sizes, outline, copper traces and vias
taken from the KiCad GenCAD export above, rounded to integer mils). Each writer in
`tools/fixtures/writers.ts` produces the format exactly as the reference parser
reads it. **Every synthetic file of a format the reference reads is accepted by the reference C++ parser** and the
BoardScope parse matches the reference output (`tests/formats/differential.test.ts`).

| File | Format / variant | Notes |
|---|---|---|
| `glasgow-testlink.brd` | Test_Link BRD, plain | |
| `glasgow-testlink-obfuscated.brd` | Test_Link BRD, byte-obfuscated | header `23 E2 63 28` |
| `glasgow-testlink-lenovo.brd` | Test_Link BRD, Lenovo variant | pin nets resolved through nail probe numbers |
| `glasgow.bdv` | BDV, obfuscated | per-line additive cipher |
| `asc/format.asc`, `asc/pins.asc`, `asc/nails.asc` | ASC multi-file set | two-space pin-name delimiter |
| `glasgow-format1.bvr` | BVRAW_FORMAT_1 | tab-separated nail probe |
| `glasgow-zlib.fz` | FZ, unencrypted (zlib) | content + description streams |
| `glasgow-rc6-testkey.fz` | FZ, RC6-CFB encrypted | generated **test** key in manifest |
| `glasgow-rc6-testkey.cae` | CAE (FZ container) | generated **test** key with CAE parity |
| `glasgow-panel.cad` | "###Panel Added" CAD | COMP/C_PIN/NET/N_VIA |
| `glasgow.cst` | CST (MFC CArchive) | CDevice/CPad records |
| `glasgow-testkey.pcb` | XZZ PCB, XOR-masked + DES | generated **test** DES key |
| `glasgow.fatf` | Fabmaster FATF REV 11.2 | no reference parser exists; written from the grammar of real jobs, one package per part in its rotated/mirrored frame, copper tracks, vias, test points |
| `glasgow.far` | Fabmaster FARC (V8.F.2 layout) | same content as `glasgow.fatf`; 8.3 outline file names for packages |
| `glasgow.a3p` | GenCAM 1.5 (IPC-2511) | no reference parser; patterns in each component's rotated/MIRRORed frame, COMPPIN nets, vias, routes, probes |
| `glasgow.f2b` | Unisoft F2B (MFC CArchive v8) | no reference parser; layout of real files: trace lists, CPinList with CComponent objects, component map, NetNames with BGA labels |
| `glasgow.tvw` | Tebo-ICT View | 6 layers (top/bottom/inner logic incl. "extra data" order, drill, route outline, empty through-layer), shapes of all types, surfaces with voids, test points, probe and fixture registries, decals |

Large performance boards (1k–200k pins) are generated on demand by `npm run bench`
into `bench/boards/` (not committed).
